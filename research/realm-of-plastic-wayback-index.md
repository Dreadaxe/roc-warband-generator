## How to submit the actual generator material

**Firefox / Windows:** On any archived generator page, press **Ctrl+S**, choose **Web Page, complete** (French: **Page web, complète**), and save it. Firefox usually creates `name.html` plus `name_files` / `name_fichiers`. Select both and create a ZIP (Windows: right click > Compress to ZIP), then attach the ZIP in the ChatGPT conversation. This captures the browser-saved HTML and resources when available. It is not guaranteed to recover JavaScript missing from the Wayback capture.

For a smaller single file: press **Ctrl+U** to open page source, then **Ctrl+S** and save the source as `.html` / `.txt`; attach it. If there is an embedded generator code block, open Firefox Developer Tools (F12), Inspector, search `generator_m`, `result2`, or `Generate Name`; right click the surrounding element > Copy > Outer HTML (HTML externe). Paste into a `.txt` file and attach. Attach the script itself if the Inspector or Debugger exposes one.

If the archive offers a `.pdf` of the original table, download the actual file and attach it unchanged; this is preferable to screenshots. Do not upload HAR/network exports containing cookies or authorization headers.
